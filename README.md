# Praveen — Unity Game Developer Portfolio

A responsive, dark gaming-inspired portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Personalize before publishing
Search the files for these placeholders:
- `YOUR_EMAIL@example.com` — replace with your professional email.
- `href="#"` and `data-placeholder` — replace with your GitHub, LinkedIn, itch.io and project URLs.
- Add real project screenshots or playable links when available.
- Confirm that each project description accurately reflects your contribution.

Pixel Adventure is labelled as in progress. Keep that status until the project is finished.

## Publish
You can host this static site using GitHub Pages, Netlify or Vercel. Upload the extracted files while preserving the folder structure.
